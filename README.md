# DeckPad — Toshiba AT200 як сенсорний Stream Deck

Планшет показує сітку кнопок. На ноутбуці (Windows 10) програма DeckPad дозволяє
вибрати, що робить кожна кнопка. Зв'язок іде **кабелем USB**, інтернет не потрібен.

## Збірка (GitHub Actions)
1. Створіть репозиторій на GitHub і завантажте в нього весь вміст цієї папки.
2. Вкладка **Actions** → *Build DeckPad* → **Run workflow** (або просто зробіть push).
3. Після збірки завантажте артефакти:
   - `DeckPad-tablet-apk` → `app-debug.apk` (встановити на планшет)
   - `DeckPad-windows` → папка з `DeckPad.exe` та `adb.exe` (скопіювати на ноутбук)

## Налаштування планшета
1. Встановіть `app-debug.apk` (дозвольте встановлення з невідомих джерел).
2. **Налаштування → Параметри розробника → Налагодження по USB** (увімкнути).
   Якщо розділу немає: Налаштування → Про планшет → 7 разів торкніться «Номер збірки».
3. Відкрийте додаток DeckPad. Він чекатиме на ноутбук.

## Налаштування ноутбука
1. Підключіть планшет USB-кабелем. На планшеті підтвердьте запит «Дозволити налагодження по USB».
2. Запустіть `DeckPad.exe` (adb.exe має лежати поруч). Угорі має з'явитись «● Tablet connected».
3. Клацайте клітинки в сітці і налаштовуйте: текст, колір, дію:
   - **Hotkey** — `Ctrl+Shift+M`, `Alt+F4`, `Win+D`, `F5`…
   - **Type text** — друкує текст (працює з будь-якою мовою)
   - **Run program** — запуск .exe з аргументами
   - **Open URL** — відкриває сайт у браузері за замовчуванням
   - **Media key** — Play/Pause, наступний/попередній трек, гучність
4. Зміни одразу надсилаються на планшет і зберігаються (`%APPDATA%\DeckPad\config.json`).
   Кнопка «Test» виконає дію через 2 секунди.
5. Закриття вікна згортає програму в трей, кнопки продовжують працювати.
   Вийти повністю: правий клік на іконці в треї → Exit.

## Якщо ноутбук не бачить планшет
- Windows 10 зазвичай сам ставить драйвер ADB. Якщо ні, встановіть Google USB Driver.
- Спробуйте інший кабель (потрібен кабель з передачею даних) і інший USB-порт.
- Запасний варіант без adb: на планшеті увімкніть **USB-модем** (USB tethering),
  у DeckPad зніміть галочку «USB cable (adb)» і введіть IP планшета в цій мережі
  (зазвичай 192.168.42.129).

## Як це влаштовано
Планшет слухає порт 38200. DeckPad на ПК підключається через `adb forward`,
надсилає розкладку кнопок у JSON, планшет шле назад номер натиснутої кнопки.
Вся логіка дій виконується на ноутбуці.
